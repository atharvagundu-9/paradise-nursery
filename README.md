# Paradise Nursery Shopping Application

Paradise Nursery is a responsive React e-commerce application for browsing and buying houseplants. It was created as the final project for the **Developing Front-End Apps with React** course.

## Features

- A welcoming landing page with company information
- 18 houseplants arranged in three categories
- Product images, names, descriptions, and prices
- Redux-powered shopping cart
- Live cart item count and total cost
- Increase, decrease, and remove cart item controls
- Responsive layout for desktop and mobile devices

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown by Vite in your browser.

## Production build

```bash
npm run build
```

## Technology

React, Redux Toolkit, React Router, CSS, and Vite.
